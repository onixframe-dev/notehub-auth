# NoteHub Auth

NoteHub Auth is a Next.js application for creating, browsing, and managing personal notes with user authentication.

## Features

- User registration, login, logout, and session refresh.
- Protected notes and profile pages.
- Notes list with search, tag filtering, pagination, detail pages, modal preview, creation, and deletion.
- Profile view and username editing.

## Getting Started

Install dependencies:

```bash
npm install
```

Create `.env` from `.env.example` and set the API URL:

```bash
NEXT_PUBLIC_API_URL=https://09-auth-three-lyart.vercel.app
```

Run the development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.
